# Data Dictionary

## Source

All data is **synthetic**, generated by the CAS Fraud Detection pipeline using distributions inspired by the [CMS DE-SynPUF](https://www.cms.gov/data-research/statistics-trends-and-reports/medicare-claims-synthetic-public-use-files) public dataset. No real patient, provider, or claims data is used anywhere in this project.

## Tables

### `claims` (50,000 rows)

| Column | Type | Description |
|---|---|---|
| CLM_ID | text (PK) | Claim identifier |
| AT_PHYSN_NPI | text | Provider NPI |
| DESYNPUF_ID | text | Beneficiary ID |
| specialty | text | Provider medical specialty |
| HCPCS_CD | text | CPT/HCPCS procedure code |
| ICD9_DGNS_CD_1 | text | Primary diagnosis code |
| amount_billed | numeric | Amount billed by provider |
| CLM_PMT_AMT | numeric | Amount paid by Medicare |
| pm_score | numeric | Process Mining score (3 layers combined) |
| structural_score | numeric | Layer A — token replay fitness |
| semantic_score | numeric | Layer B — CPT-specialty coherence |
| temporal_score | numeric | Layer C — timestamp anomalies |
| xgb_score | numeric | XGBoost prediction probability |
| if_score | numeric | Isolation Forest anomaly score |
| cas_score | numeric | CAS composite score (provider-level) |
| oar_alert | integer | O-A-R alert: 0 = no alert, 1 = alert |
| oar_confidence | numeric | O-A-R confidence score |
| n_signals | integer | Number of active signals (0-3) |
| is_fraud | integer | Ground truth: 0 = legitimate, 1 = fraud |
| fraud_type | text | Fraud profile (F1-F5 or "none") |
| fraud_narrative | text | Auto-generated explanation (alerts only) |
| PRVDR_STATE_CD | text | Provider state code |
| service_hour | integer | Hour of service (0-23) |
| submission_lag | integer | Days between service and billing |
| flow_length | integer | Number of steps in process flow |

### `providers` (800 rows)

| Column | Type | Description |
|---|---|---|
| AT_PHYSN_NPI | text (PK) | Provider NPI |
| specialty | text | Medical specialty |
| n_claims | integer | Total number of claims |
| fraud_rate | numeric | Proportion of fraudulent claims |
| cas_score | numeric | CAS composite score |
| avg_pm_score | numeric | Average pm_score across claims |
| avg_amount | numeric | Average amount billed |
| n_alerts | integer | Total O-A-R alerts |
| PRVDR_STATE_CD | text | Provider state |

### `alerts` (subset of claims where oar_alert = 1)

| Column | Type | Description |
|---|---|---|
| id | uuid (PK) | Auto-generated |
| CLM_ID | text | Claim identifier (FK) |
| AT_PHYSN_NPI | text | Provider NPI (FK) |
| status | text | pending / investigating / confirmed / dismissed |
| n_signals | integer | Number of active signals |
| oar_confidence | numeric | O-A-R confidence score |
| fraud_narrative | text | Auto-generated explanation |
| created_at | timestamp | Auto-generated |

## Fraud profiles

| Code | Name | Description |
|---|---|---|
| F1 | Severe upcoding | Low-complexity CPT billed as high-complexity |
| F2 | Phantom billing | Services billed but never rendered |
| F3 | Unbundling | Single procedure split into multiple charges |
| F4 | Surgical upcoding | Office visit billed as surgical procedure |
| F5 | Mild upcoding | One-level CPT inflation ($45 difference) |
